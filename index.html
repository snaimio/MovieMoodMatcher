About This Project

Movie Mood Matcher is a lightweight web application that recommends movies based on the user's current emotional state. Instead of browsing endlessly, users receive personalized, mood-aligned suggestions within seconds, reducing decision fatigue and creating a more enjoyable viewing experience.

The Tech Stack:

  • Data: Real-time fetching from the TMDB API endpoints (Trending, Search, Discover).
  • Persistence: Custom Local Storage implementation to save your personal Watchlist.
  • Design: Responsive CSS Grid layout with a custom dark mode theme.

This project was created as an educational purposes to demonstrate proficiency in DOM manipulation, 3rd-party API usage and Local Storage implementation.
